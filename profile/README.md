# Scripts Zeus

Scripts FiveM desenvolvidos para o servidor **Apocalipse Z**, cidade de apocalipse zumbi.

- **Standalone:** nenhum depende de framework. A integração fica isolada em `bridge/`.
- **Distribuição:** cada script é publicado como `.zip` nas *Releases* do seu repositório.
- **Suporte:** abra uma *Issue* no repositório do script, usando o modelo de bug ou de melhoria.
